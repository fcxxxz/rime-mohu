## ② 词证据分歧门：交付并启用

- 引擎 `tiger_engine_word_disagreement`：top1 在码点对齐公共前缀后接
  不成词（含跨词界中分窗口：暴利/暴力的「暴」在公共前缀里，检测窗从
  分歧点前一码点起 2–4 字查 freq_rank）而 top2 接词典多字词 → 开门。
  测试 `make tigerengine-word-gate`（5/5 分类断言，含中分边界案例）；
  Lua 绑定 + 过滤器接线（旧 dylib 无 ABI 时逐字节旧行为）；
  `mohu.yaml` 默认 `word_gate: true`。
- 实现过程中修掉一个 UTF-8 回退错位 bug（prev 循环检查 `text[prev-1]`
  导致窗口起点停在码点中间，由分类测试暴利案例暴露）。

### 延迟修正与修复（2026-09-13 深夜）

此前报告的 C3「p50 16.7ms」有测量口径错误：export 基准用了 ONNX
默认多线程，而引擎 scorer 固定单线程——**真实部署形状（K=5、单线程）
实测 p50 32ms**。修复：semantic_infer.h 线程 1→2（`MOHU_SEMANTIC_THREADS`
可覆盖），引擎 C ABI 实测 **K=5 p50 18.2ms / p95 19.0ms / p99 19.8ms**
（降 44%）。推理在 filter 阶段短时运行，与 beam 解码不并发争用。
全套语义/门控/词门测试通过。若需再降一档：C2 尺寸（~10M）同配方重训
预计 ~8ms、质量介于 C2 与 C3 之间（待训练验证）。
