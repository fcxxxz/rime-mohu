# Rime 同步助手

把 Rime 的「用户数据同步」做成**无常驻进程**的定时任务，在后台自动执行：

- **开机同步**：登录系统后自动同步一次（macOS 走 LaunchAgent，Windows 走计划任务）
- **空闲同步**：按设定的检查间隔被系统拉起，检查键鼠空闲时间，达到设定分钟数才同步；持续空闲只同步一次，恢复操作后重新计时。实际触发时间最多比设定值晚一个检查间隔
- **有更新才执行**：真正调用同步前先做门卫检查——本地用户库（`*.userdb`，打字产生的调频/造词）和同步目录（云盘带来的其他设备新快照）都没有比上次同步更新的文件时，直接跳过。因此触发时几乎总是真有数据要同步；纯粹改了配置文件而没动用户库时，会等下一次有数据变化时一起同步
- **没有关机同步**：无常驻进程就接不到关机信号。未同步的数据不会丢——数据在本机用户库里，下次开机同步会自动补上

**平时系统里没有任何同步进程**：macOS 版是纯 bash 脚本（无需 Python），Windows 版用系统 PowerShell，每次被调度器拉起、跑完即退。同步动作调用各平台原生命令：macOS 执行 `Squirrel --sync`，Windows 执行 `WeaselDeployer.exe /sync`。同步目标由 Rime 自己的 `installation.yaml` 中 `sync_dir` 决定，本助手不复制任何文件。

## 使用

把整个 `Rime同步助手` 文件夹放到任意位置（建议放在 Rime 配置目录里），然后：

**macOS**：双击 `安装.command` 注册并立即运行一次；双击 `卸载.command` 注销。
**Windows**：双击 `安装.bat` 注册并立即运行一次；双击 `卸载.bat` 注销。

## 设置：直接编辑「同步设置.conf」

打开文件夹里的 **`同步设置.conf`**，按注释修改后保存即可，下次检查自动生效：

```
空闲同步: 开        # 开 / 关
空闲分钟数: 10      # 1 - 1440
开机同步: 开
检查间隔分钟数: 5   # 1 - 1440，决定多久检查一次
```

例外：**「检查间隔分钟数」**写进了 launchd/计划任务的调度配置里，改完需要重新双击一次 `安装.command`（或 `安装.bat`）才会生效，其余项保存即生效。

命令行方式（可选）：

```bash
bash rime_sync.sh status    # 查看注册状态和上次同步结果
```

## 文件

- `同步设置.conf`：**用户设置，直接编辑这个文件**
- `同步状态.json`（自动生成）：上次同步的结果，供 status 查看
- `同步游标.txt` / `sync-cursor.json`（自动生成）：开机时间和空闲武装状态，用于判断是否需要同步
- macOS LaunchAgent：`~/Library/LaunchAgents/cn.zrmfans.rime-mohu.sync.plist`（RunAtLoad + 按检查间隔定时）
- Windows 计划任务：`RimeMohuSync`（登录触发 + 按检查间隔重复）

## 注意

- 多台设备同步时，`sync_dir` 应指向同一个云盘目录，并让云盘完成上传后再在另一台设备同步，避免冲突。
- 空闲判定的粒度是检查间隔（默认 5 分钟）：设 10 分钟空闲，实际会在空闲 10～15 分钟之间触发。间隔设得越大越省，触发也越迟钝。
