## 华南虎码表本体

华南虎与虎码同构：字根带大码+小码（`码表-字根.txt` 共 987 个字根形，如 `文 Aw`、`辶 Lv`、`火 Ah`），单字全码 = 各根大码序列 + 末根小码（`这 = 文+辶 = a+lv = alv`）。数据质量很好：

- 全码 95,180 字，每字唯一码（无虎码式镜像多码），码长仅 3/4；
- 8105 通用规范汉字全覆盖；官方简码（一简 23、二简 552、三简 5,672）全部是同字全码前缀，出简让全零特判。

## 结论

**华南虎原版是一套很强的纯形码。** 加权码长 2.0580、字均当量 2.2731、键均当量 1.1039 全场最优；换手率 60.49% 全场最高（双手交替节奏最好），同指大/小跨都最低。高频段重码控制极好：Top 500 零选重零重码、Top 1500 仅 2 选重、Top 3000 才 16 重码字，前三千字的重码控制好于所有音形臂。代价是左右手均衡垫底（94.37%，右手 52.8%）和小指干扰略高（0.32%），8105 全集重码 419 介于魔然（601）与简单鹤（279）之间。

**魔虎规则换华南虎字根，与现行魔虎同一水平、各有胜负：**

- 高频段（Top 500）两者都零选重零重码；华南虎前二的小指干扰 0.00%、同指小跨 6.71% 好于虎码前二的 0.12%/7.45%——高频手感华南虎略优；
- 全集（8105）华南虎前二多 39 重码字（358 vs 319）、多 37 选重（371 vs 334），加权重码 0.113% vs 0.099%，差距不到 0.5 个字的千分位；
- 码长与当量打平（2.2158 vs 2.2144，字均 2.5182 vs 2.5186，键均华南虎微优 1.1358 vs 1.1368）；
- 键盘分布：虎码左右互击更均衡（99.47% vs 98.32%）、同指大跨更少（2.21% vs 2.46%）；华南虎同指小跨（7.76% vs 8.42%）与小指（0.09% vs 0.21%）更好；
- 根本原因在辅码离散度：同双拼音节组内，虎码前二重复槽 10.14%、华南虎前二 10.19%，分离同音字的能力基本相同，决定了总成绩贴身。

对比旧基线：两个"前二"音形臂都大幅好于魔然原版辅码（8105 重码 601→319/358）；简单鹤原版重码最少（279）但 26 字走拼音回退、加权选重高达 12.30%（500 档 42 选重），高频段选重压力远大于两个前二臂（0.12%/0.13%）。注意简单鹤是小鹤双拼，手感指标含双拼布局差异；华南虎原版是纯形码，码长天然占优，与音形臂不同类，只作参照。

**夜莺**是纯音码方案（无形码辅码层），此前只出现在整句/上下文排序对比（`docs/knowledge/cross-candidate-ordering.md`），不参与字根辅码维度赛码，本表无可比臂。

若要在 mohu 里真换华南虎辅码：`data/hnh_full_codes.tsv` 每字一码，比虎码还干净（无需挑主码、无镜像码），接入 `tools/gen_tiger_aux.py` 的等价流程即可。

## 复现

```bash
uv run python research/tiger_aux/extract_hnh_codes.py \
  --full "~/Downloads/华南虎/码表-单字全码.txt" --single "~/Downloads/华南虎/码表-单字.txt"
uv run python -m research.tiger_aux.experiment \
  --race-profile research/tiger_aux/output/race_profile.tsv \
  --moran-dict research/tiger_aux/data/moran_fixed_simp_legacy_chars.tsv \
  --moran-aux research/tiger_aux/data/moran_chai.tsv \
  --output research/tiger_aux/output
uv run python -m research.tiger_aux.verify_output   # 72 行全部复算通过
uv run python -m unittest research.tiger_aux.test_experiment research.tiger_aux.test_generate_charts  # 49 全绿
```
