# 两个完整词单元的上下文：实现修复与未通过的原句

日期：2026-10-09。用户希望评分上下文按分词后的两个词取样，而不是按两个字
滑动；验收输入为 `vgxjuvijxwudi` 和 `xmzlvgxjuvijxwudi`。

## 实现发现与修复

现有 `resolve_word_context` 已按模型词表逆向最大匹配取最后两个词。
本地探针可得到 `现在 -> [<s>] [现在]`、
`输入法编辑 -> [输入法] [编辑]`。但不能据此断言整句解码已经使用它：

1. `expand_range` 的字符模式内部边限制也套在词模式上。词模式原本跳过句中
   静态多字词，导致有完整 `现在` 词边也只能尝试 `现 + 在`。
2. `set_decode_context` 只设置字符状态，`rebuild` 没有播种词状态。
   词模式读取上屏历史后仍从 `[<s>] [<s>]` 开始。

修复只针对主模型为 `MHKNM01` 的词模式：允许全码、非注入的词条作为内部边；
最近上屏文本用主模型词表解析成至多两个词并播种解码。简词开关、简词档位、
严格码长规则、rank >= 90 的注入词限制仍保留。

主解码与独立词评分器的词 ID 不能混用。上下文切分缓存加入模型身份，
词模式解码显式用主模型词表；加载另一个词评分器不会改变主解码 ID。

**这是允许词路径及接通词上下文，不是强制最长词切分。** 单字回退路径仍可
胜过多字词路径；不能声称已经禁止所有候选把 `现在` 拆开。
默认 V5 字符模型未切换，schema 未修改，动态库未重建或部署到用户目录。

## 确定性回归

`tests/tigerengine_word_units_test.cc` 自建小型二进制模型与临时词表，
无需安装实验模型，无跳过分支。修复前复现词上下文不参与排序，
以及上一版直接放开词模式后绕过简词限制的问题。修复后检查：

- 完整词边 `[现在] [整] [句] [直接] [无敌]` 可参与长句解码。
- 逐步追加、删除输入与完整重算的输出逐字节一致。
- 简词默认关闭、启用时档位限制、严格码长与注入词限制。
- `[现在]` 与 `[在]` 的上下文不同；两个完整词都参与打分。
- `输入法编辑` 与 `词典编辑` 同以“编辑”结尾，但前一个词不同仍作废缓存。
- 单词窗口、清除上下文、重复设置与无汉字上下文的行为。
- 独立评分器使用不同词 ID 时，主解码与评分缓存互不污染。

通过命令：`make tigerengine-word-units`，以及
`make -j3 tigerengine-context tigerengine-word-score tigerengine-safety`。
词评分测试的独立模型分支通过；可选合并容器分支因
`/tmp/mohu-sentence-ngram-v6-merged.bin` 不存在而跳过。

## 真实模型结果与边界

用新源码编译独立探针，主模型为已有 `mohu-word-kn4.bin`，词表为
`tiger_sentence_native/data/zrm/mohu_zrm.lexicon.txt`，beam 200，
reading prior 1、composed reading prior 1.3、word edge 0.5、
text lexicon / word form 6.5。不载入个人模型或用户词库。

| 输入 | 词模式首选 | 预期候选位置 |
|---|---|---|
| `vgxjuvijxwudi` | 整剧直接无敌 | 整句直接无敌：第二 |
| `xmzlvgxjuvijxwudi` | 现在整局直接无敌 | 现在整句直接无敌：第二 |
| `fzjnqmxnwjku` | 费尽千辛万苦 | 第一 |
| `bmjimabc` | 编辑嘛表 | 未达到预期 |

以上为离线 native 候选，不是部署后的 Squirrel 菜单；`bmjimabc` 是一次性
整句输入，不等同于先提交“编辑”再输入 `mabc`。

另外，按完整 `[现在]` 条件直接对词 `整句/整车/整剧` 评分，kn4 给分为
`-20.3517/-17.8127/-20.0`（最后一项是 OOV 地板）。此处已经保留“现在”
的词边界，仍偏向“整车”，说明不能仅通过扩大窗口解决现有模型的搭配偏差。
候选首选仍常走单字路径，因此也不能把“现在已经作为一个词参与”误报成
“现在在所有胜出路径上都不可拆”。

结论：词模式实现中的两处断点已修，但原长句验收未通过；不启用旧词模型，
不删除读音，不为单个例子写强制替换，不改变正在使用的默认 V5 配置。
后续需要单独验证词界约束/词级模型质量，并与字符回退、原有输入用例一起
验收，不能把这次确定性规则测试当作真实输入效果通过。
