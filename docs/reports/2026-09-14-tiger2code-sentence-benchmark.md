# 2026-09-14/15 虎2码整句基准：魔虎框架 vs 万象虎 vs 虎整

> 三个口径（49,794 句，5-25 字、纯 CJK、多来源、全局去重）：
> (A) 万象虎「两码整句」规则（每字前 2 码，一简字 1 码 + `'`，≈2 键/字）——魔虎 vs 万象虎，码流一致；
> (B) 虎整原生打法（每字最优码 + 挤让，常用字 2 码/生僻字让位后全码，≈2.34 键/字，逐键 + 提前上屏）——虎整 vs 魔虎@同码流；
> (C) 每字全码（≈2.39 键/字）——参考口径。

## 结论摘要

- **两码口径（主问题：魔虎模型+框架 vs 万象虎）**：魔虎 V5 top1 **89.40%**，
  万象虎 **67.32%**，配对差 **+22.08pp** [21.74, 22.42]；held-out（从未入魔虎训练）
  **82.80% vs 65.39%，+17.40pp** [16.70, 18.11]。
- **虎整原生打法口径**：虎整 top1 **98.08%**（日常语料 98.9-99.2%，与用户体感
  「≈99%」一致；held-out 96.19%）；魔虎同码流 **99.53%**（held-out 98.77%）。
  配对差：全量 **+1.46pp** [1.30, 1.58]，held-out **+2.57pp** [2.12, 2.93]，
  日常域收窄到 **+0.74pp** [0.58, 0.87]。
- 全码参考口径：魔虎@全码 99.56% vs 虎整@全码 96.18%（+3.38pp）——虎整的最优码
  打法（98.08%）反而高于其全码打法，证实最优码分布才是其模型调优目标。
- **提前上屏消融**：关闭后 96.00% vs 开启 95.90%（全码口径同批 1,000 句）——
  该功能不贡献准确率，价值在省尾码交互。
- 万象虎 top5 仅比 top1 高 4.8pp（Rime 管线只产 1 条整句候选）；魔虎 top5
  97.68%（两码）/99.99%（最优码）。万象虎唯一获胜语域：《论语》86.2% vs 79.3%。

## 勘误与口径演化记录（2026-09-15）

1. 首轮把虎整原生流编成「每字最短码」，**句中混入一简码**——其 README 明文
   「一码字只在整段就是那一码时合法」，属非法输入，14% 为无效测量。
2. 第二轮改全码（96.18%），仍非其设计打法。
3. 终口径按其词典结构与挤让规则：**常用字（前 1500）用词典唯一最优码
   （多为 2 码，如 是=ot、班=np、的=ue）；被一简字挤占 2 码位的生僻字用让位后
   编码（桶内第 1 名所属码，如 灮=cpeh、黒=phh）；无简码生僻字用全码**。
   挤让调整覆盖 1,605 字、语料 836 句（0.15% 字次），单独补测后合并。
4. 魔虎@最优码流使用同一词典编码并集的 lexicon（其自有拼写全保留），
   码流与虎整逐句一致。

## 参测系统

| 通路 | 模型/词库 | 输入与协议 |
|---|---|---|
| 魔虎 V5 | `libtigerengine.dylib`（beam=200、word_edge_weight=1.5、无用户模型）+ `mohu-sentence-ngram-v5.bin`（c2c148ea…） | 各口径码流，一次性整流（其原生形态；C 引擎） |
| 万象虎 | zhhwux/wxzhh 原版：真实 librime 1.16 + octagram（wanxiang-lts gram 官方参数）+ 全部自带词库 | 两码流，set_input 注入 |
| 虎整原生 | TigerClaw Rime 原包（纯 Lua beam + 原配 TCSKNM e3953f8f…） | 最优码挤让流，**逐键 process_key**，提前上屏按其默认规则触发（三代连续 + ≥0.995 + 同边界 + 三键冷却） |

魔虎两码 lexicon：字 24,689 行（镜像 wxh 三档派生）+ 魔虎词表 128,301 词；
魔虎最优码/全码 lexicon：虎整词典拼写 ∪ wxzhh 全码并集 + 词表逐字重编码；
字频均沿用魔虎 freq_rank 体系。编码权威表 wxzhh 8105（保证万象虎可达）。

## 语料

50,000 句、5-25 个纯 CJK 字符、全局去重；206 句含表外字剔除后实评 49,794 句。
**held-out 11,730 句**从未入魔虎训练（frozen_v1 + neutral_v1：天涯2026、诗经、
论语）；**extracted 38,270 句**多域采样但在魔虎 V5 训练语料内（全量数字对魔虎
偏乐观，公平结论以 held-out 为准）。wanxiang-lts gram 训练语料不可审计。

### 错例风格

- 万象虎（16,274 错）：语义近邻（利益→利润、痛哭→痛骂）。
- 魔虎两码（5,279 错）：个别字位（寝房→宁房、哦→啊）。
- 虎整最优码（956 错）：文言专名与同码难字（牛彔→牛隶、张奂→张秧、祝釐→祝来和）。
- 魔虎@最优码（234 错）：同上更稀（鄠→向帮、毗→毘）。

## 方法学验证记录

1. 万象虎管线完整（gram 加载确认、零空候选、冒烟一致）；无 zuci 对照 A/B 证明
   其词库参与组句。
2. 虎整：KN 同步按页加载无静默回退；提前上屏按其规则触发并经开关消融。
3. 逐键探针为真实键事件（`process_key`），预测 = 已上屏文本 + 菜单首选；
   虎整解码为纯 Lua 实现，5 万句需 12 进程约 1 小时（魔虎 C 引擎 11 秒）。
4. tigress（虎单/虎词）隔离部署编译失败未加载；对整句流无影响。
5. KPC：两码 ≈2.0（一简字另需 +1 个 `'`）；最优码 ≈2.34；全码 ≈2.39。

## 限制与不可外推项

1. extracted 切片在魔虎训练语料内；虎整/万象虎语料不可审计。
2. 虎整跑交互协议、魔虎跑一次性解码（各自原生形态）；提前上屏消融显示开关
   对虎整准确率无影响（±0.1pp）。
3. 基准为固定码流 + 一次性判定，不含人工加码纠错与选重；虎整真实用户在难字上
   会补一码，日常体验高于固定流下限。
4. 关闭用户词典/自学习/跨句上下文；滤镜出厂默认；冷启动单句行为。
