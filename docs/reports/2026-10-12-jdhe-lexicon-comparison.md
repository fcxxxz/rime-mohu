- 脚本：`research/jdhe_lexicon_compare.py`（`uv run python research/jdhe_lexicon_compare.py` 复现）
- 对比对象：
  - 简单鹤侧 = `cn_dicts/jde/{jde,jde_ext}.dict.yaml`（固定形码表 9.3.0）+ `cn_dicts/pinyin/{base,tencent,moe,words,8105,41448}.dict.yaml`（拼音词库，挂 `script_translator`）

- 单字重码/手感对比见 [2026-10-10-hnh-auxiliary-benchmark.md](2026-10-10-hnh-auxiliary-benchmark.md)，本文不重复。

## 1. 整句词库覆盖：jdhe 词 99.9% 被 mohu 覆盖，mohu 多出 45.6 万万象词

| | 词形数 | 说明 |
|---|---:|---|
| jdhe 拼音词库合计 | 1,769,555 | base 999,777 + tencent 698,608 + moe 126,559 + words 24,557 |
| mohu 整句词库合计 | 2,224,254 | 同血统四源 + **万象 453,911** + classics |

共同来源几乎逐行同源：tencent 两边同为 698,608 行（同一快照），base 999,777 vs 999,752。mohu 独有词按整句词频排前的多为万象系新词/人名（原宿、欣泰、王珂、魏鹏……）。

## 3. 简码机制：同为声母简拼思路，取舍相反

码长×词长分布（词形去重）：

| 词长 | jdhe | mohu |
|---|---|---|
| 2 字 | 2 码:1,218 ＋ 全码(4 码双拼双拼):94,524 | 2 码:562 ＋ 全码:45,023 |
| 3 字 | 3 码:21,992 | 3 码:8,465 |
| 4 字 | 4 码:49,758 | **4 码:71,094** |
| 5 字+ | 4 码:5,831 | **4 码:6,733** |

码形规则两边几乎一致：

- 2 字词全码 = 双拼+双拼 4 键（阿爸 `aaba` 两边同形）；2 码简词 = 声母+声母（爱情 `aq`）。
- 3 字词简码 = 声母×3（办不到 `bbd`），两边都不收 6 码全码进固定表——三字词全码输入走各自的 script/整句通道。
- 4 字词简码 = 声母×4（傲岸不群 `aabq`）。
- 5 字+ 简码 = 前三字声母+末字声母（jdhe：埃菲尔铁塔 `afet`）。mohu 同式且**额外给前二+末二别名**（阿波罗计划 `ablh/abjh`）。

取舍差异：jdhe 在**二字/三字**短词简码上量大（三字简码是 mohu 的 2.6 倍、二字全码是 1.9 倍）；mohu 在**四字/长词**简码上覆盖更广（四字简码多 43%，≥4 字词带 ≤4 码简码的共 75,249 对 jdhe 的 46,510）。这与架构一致：jdhe 靠 176 万词拼音 `script_translator` 直出全量词，固定表主要承担简码+排序；mohu 靠原生整句引擎消费全量词库，主表只收高频道+简码注入。

## 4. 词频权重

- jdhe：8105 单字权重最大 76,938,354（字频主导，配合固定表 `initial_quality: 10` 压制拼音候选）；base 词权重上限 664,963；tencent/moe 权重封顶 100（相对档）。
- mohu：整句词频上限 635,391，129.7 万词带权重；主表 `sort: original`，同码序靠行序而非权重。
- 共同来源（base/tencent/moe）词频体系同血统，差异主要是各自重整后的档位。

## 5. 架构差异（词库挂载方式）

- 简单鹤：`script_translator`（dictionary=pinyin，prism=jde，小鹤双拼+直接辅助 smart 译码）出全量词 + `table_translator@jde_fixed`（quality 10）出固定简码 + octagram `.gram` 整句 + `predict.db` 联想。
- mohu：lua `mohu_express_translator` 查主表（简码+高频道全码）+ 原生 `mohu_sentence` 引擎消费 254 万行整句词库（lexicon 高频表 + words.dict 全量），无 octagram。

## 6. 结论

1. **词表覆盖 mohu 是 jdhe 的超集**：共同词 176.8 万，jdhe 独有不足 0.1%；mohu 多出的 45.3 万词全部来自万象语料，集中在 3 字/4 字段。
2. **简词（声母简拼）机制同形**：2/3/4/5+ 字词的简码码式两边一致；jdhe 短词简码更厚，mohu 四字及长词简码更厚（且有双别名）。
3. **长词覆盖同源**：≥4 字词交集 107.8 万，jdhe 几乎无独有；两边都收 38 字超长句词。
4. 单字维度（重码、码长、手感）维持 10-10 基准结论：简单鹤全集重码最少（279）但高频选重压力最大。
