# 词级解码判决、青简对照与语义层结论（2026-09-13）

承接 [词边先验报告](2026-09-13-word-edge-prior.md) 的语义救援分析
（C2 救回 1% / Qwen3-0.6B 52% / Qwen3.5-0.8B 58%）。本文记录其后的四项
结论与 C3 计划的依据。

## 1. 「码表补词」被否决（机制证明）

给同码补另一个词（如 `bkli` 补「暴利」）会发生三件事：

1. 那一句修回（两词加分抵消，回到三元裁决）；
2. **任何恰好因词表不对称被误救回的句子重新翻错**；
3. 词边先验对「合法词 vs 合法词」的分辨力**本就依赖词表不完整**——
   「只吃」是完全合法的词，哪天入表，旗舰句当场复发。

词边先验修复样本（12 例抽查）约九成是「错读法不成词」（内些/膜是/
嫁张/哈弗），这部分是永久性结构收益；会被词表完整性侵蚀的只有词对
冲突那一圈。**码表管存在性，选择性必须归语义层**——这是本日的核心
架构结论。

## 2. 词级解码：已试、已判（仓库在案 + 外部对照）

自家实验（2026-09-02 七变体 + kn5）：

- MHKNM01 词级 KN 三元＋SGNS 词向量语义回退（`train_wordkn.cc`），
  1.5GB 七源语料重训（kn5, 797MB）；
- 词信号修好率 **13.16%** vs 字符信号 **45.05%**（3 倍差距）；
- 根因是分词管线：jieba 用户词典单字 400 万级词频 → 上海/三国系全部
  被拆单字，词层零整词计数（gold 14% 缺表＋12% 零计数）；kn6 修复无
  可复核产物；
- 词模式解码代码在引擎中保留，从未上整句基准。

青简（qingjian）外部对照——词级能用但没赢：

- 纯词级解码（词图＋bigram Viterbi），字级 Transformer 仅停顿后异步
  重排；
- 自测：冷语料整句 8322 句命中率 **41.6%**（神经重排 +4.3pp）；个人
  日志回放整句 90.1%（个人词级 n-gram 在线）；逐键 0.2–4ms；
- 未命中分析：328 条整句失误中 **294 条同音换字**——词频解决不了
  选择性，它自己的异步语义层就是为此存在；
- 41.6% 与本仓 harness 的 bgw 41.0%／万象 lts 45.5% 同带（口径不同，
  不可直接比），低于 V5 底座（62–66%）约 20pp。

青简词级可行的四个结构条件（我们当年缺的）：训练与解码**同源词表**
（语料用词库自身分词）、词层是其**第一信号**而非叠加在强字符模型上的
边际信号、**在线词级个人 n-gram**（无个人化断层）、OOV 返回 None 走
词频兜底罚分。

**判决**：词级解码相对「V5＋词边先验」的净新增收益只剩语料内恰好有
整词搭配证据的一小片选择性（自家实测 13%），重启前提（同源分词词典、
可商用语料重训、个人词层重建、全套行为重验证）未满足前不再投入。

## 3. C2 公允评估

- 不是废物：2026-09-10 同方法 89,970 真实菜单上唯一净收益为正的后端
  （TinyCharLM 大幅负），12ms 级进程内推理；
- 但上限低：probe 修好 71 例的 CI 在保护修正后含 0；对抗词对类
  救回 1%（201/204 主动维持错误答案）；
- 根因＝**分布外＋容量**：训练分布（生产菜单）里几乎没有词对冲突类；
  老师 Qwen3-0.6B 同协议 52% 证明监督信号存在、可蒸馏。

## 4. 战略归位

频率/结构层（字符三元＋词边先验）管「像不像中文、是不是词」；
选择性层（语义学生＋门控）管「这句话要哪个词」。C3＋词证据分歧门是
当前唯一同时对症、不碰码表、不重建解码器的路径。计划见训练合同
`docs/knowledge/qwen-semantic-reranker-training.md` 的 C3 章节。

复现脚本：`research/lm_sentence_compare/regression_semantic_rescue.py`、
`regression_qwen_rescue.py`、`word_edge_grid_analysis.py`。
