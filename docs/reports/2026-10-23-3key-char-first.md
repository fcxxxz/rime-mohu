# 三码位「字先词后」重排——被顶字不再沉到声母简词之后

- 日期：2026-10-23
- 判例：无重版（魔虎·小鹤）`bad` 打 吧 落到第 4 选（叭→不安定→保安队→吧）、
  `ciw` 打 次 被存储为压（瓷→存储为→次→粢）。
- 用户拍板：字先词后（owner 字钉首 → 其余阶梯字按字频 → 简词按竞速序殿后），
  镜像四码位已定稿的「被顶字保次选」（bdc5dcc，2026-10-13）。

## 根因

整句模式三码位（双拼+首辅，与三字声母简词共用码空间）的菜单顺序 = 根词表
同码组 rank 列（实验证实：把 吧 从 rank 4 提到 2，引擎菜单立即翻转；分数列
不决定显示序）。组序规则自 ddc4fbc（10-12 简单鹤三字简词导入，B 方案）起为
「主表行在前、根词表独有阶梯行殿后」——未占三简位的高频字一律沉到简词后。
逐提交核对：bad/ciw 等组行序自 10-12 至今（含 953ca97 无重并入、446dde7
rank 对齐、3295387 复合规则）从未变过；测试者"上个版本没问题"应为 10-12
之前的旧构建（latest 资产随 push 滚动更新）。

## 波及面（修复前，根词表全量统计）

- 三码基础组 11,603，其中字词混合组 2,917；
- 被压到简词之下的字行 2,578，其中字频前 500 的高频字 **203 个**
  （啊 55、把 76、吧 146、本 132、比 182、白 151、边 143、别 168、并 205 …）。

## 修复

- 新工具 `tools/fix_lexicon_3key_char_first.py`（干跑/`--apply`，幂等）：
  仅重排字词混合三码组——owner 字（现行 rank 最小字行，即主表三简/简码行）
  钉首，其余阶梯字按字频名次升序（20001 占位殿后），≥2 字行按竞速序殿后；
  纯字/纯词组不动。重排 1,421 组。
- `tools/sync_rootlex_3words.py` 组装规则同步改为字先词后，未来主表三码词
  变更重放同序，防止规则回退。
- `make mohu_lexicons` 重建三份词表；`XXX/` 三码筛镜像行由构建从基础行
  同 rank 派生，自动跟随。

## 验证

- 码位抽查（flypy 派生表 + 引擎实跑）：
  `bad`=[叭, 吧, 不安定, 保安队]、`ciw`=[瓷, 次, 粢, 存储为]、
  `aad`=[吖, 啊, 呵, 暗暗地]、`bms`=[辩, 边, 白马寺, 绊马索]、
  `bau`/`biv` 全字提词前；纯词组 `yju` 有阶梯字（掞）时按规则提到简词前。
- 整句回归：词表内 2–4 词拼接 600 条模拟输入，新旧词表解码 top 路径
  **0 差异**（0.00%）——3 码 rank 改动只影响该码位菜单显示，不进整句解码。
- 简词功能保留：无字竞争的纯词码位（如 `yju` 词区）行序与可达性不变；
  有阶梯字的码位简词按拍板规则让位。
